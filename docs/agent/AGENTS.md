# AI 笔记目录

> 这里放**事实**，不放设计意图。前身是 `.workbuddy/memory/`（2026-10-04 迁到 `docs/agent/`，
> 因为 `.workbuddy` 是某个工具专用的私有目录名，其它 AI 读不到；`docs/` + 本目录的 `AGENTS.md`
> 是工具中立的通用约定，人和任何 AI 代理进项目都能直接发现）。
>
> 行为守则见仓库根 [`AGENTS.md`](../AGENTS.md)；设计案见 `DESIGN_*.md`；决策留痕见 `DECISIONS.md`。

## 文件分工

| 文件 | 作用 |
|---|---|
| `MEMORY.md` | 当前有效的技术事实：引擎实测结论、已知坑、调参结果。根 `AGENTS.md` §9.8 所指「以它为准」就是这份 |
| `YYYY-MM-DD.md` | 当日改动与踩坑日志，**只追加**，不回改 |

## 写入规则

1. 引擎 API 名、枚举值、路径、插件版本：**必须本机实测后才能写进来**，不写推测。
2. 与 `DESIGN_*.md` 冲突时：设计意图以设计案为准，运行期事实以本目录为准。
3. 坑写「现象 + 根因 + 规避办法」三件套，只写现象的等于没写。
